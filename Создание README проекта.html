SQL Step Project — Sofia Kucheruk

📌 Project Overview

This project contains a collection of SQL queries and database design tasks completed in MySQL.

The project is divided into two main parts:

  1. Employee Data Analysis — analytical SQL queries based on an employee database.

  2. Course Management Database — designing a relational database from scratch, inserting data, analyzing relationships, and detecting duplicate records.

The project demonstrates practical SQL skills including JOINs, CTEs, aggregation, filtering, window functions, temporary tables, transactions, constraints, and duplicate detection.

Part 1 — Employee Data Analysis

The first part uses an employee database containing information about employees, departments, managers, and salaries.

Questions I Wanted to Answer From the Dataset

1. Which department was the largest in each year, and what was its average salary?

This query identifies the largest department for every year and calculates its average salary.

Result: The query returns the largest department for each year together with its employee count and average salary.

2. Which current manager has been working in the position the longest?

Result: Returns the current manager with the longest management tenure.

3. How did the average employee salary change by year before 2005?

Result: Shows the average employee salary for each year before 2005.

4. What is the current average salary in each department?

This analysis uses only the employee's current department and current salary.

Result: Returns the current average salary for every department.

5. What was the average salary in each department for each year?

Result: Shows average salary by department and year.

6. Which departments currently have more than 15,000 employees?

Result: Returns departments with more than 15,000 current employees.

7. Who is the longest-serving current manager?

Result: Returns the current manager who has been employed by the company the longest.

8. Which 10 current employees have the largest salary difference compared with their department average?

A CTE is used to calculate the average current salary for each department. The query then compares every current employee's salary with the average salary of their department.

Result: Returns the top 10 current employees whose salaries differ the most from their department's average.

9. Who was the second manager of each department?

A window function is used to assign a sequence number to managers within each department based on their management start date.

Result: Returns the second manager for every department together with their employment and management dates.

The second part focuses on designing a relational database for managing courses, teachers, and students.

Questions I Wanted to Answer From the Course Database

1. How many students has each teacher worked with?

Result: Returns each teacher and the number of students assigned to them.

2. Which rows are duplicated in the students table?

Three duplicate records were intentionally created and then identified using GROUP BY and HAVING COUNT(*) > 1.

Result: Returns records that occur more than once in the students table.
